常见报错排查

报错信息是程序在跟你说话。先完整读一遍报错的最后一行，再来这里对号入座。

python3: command not found / 'python' 不是内部或外部命令

终端不认识 python 命令，八成是没安装，或安装时没勾选 Add to PATH。

解决：先试 python --version；都不行就去 python.org 下载安装，Windows 安装时务必勾选 Add to PATH。

IndentationError: unexpected indent

缩进错了。Python 靠缩进区分代码块，多/少一个空格都会报。

解决：检查报错行号附近，统一用 4 个空格缩进；不要混用 Tab 和空格。

SyntaxError: invalid syntax

语法写错了，最常见的是括号、引号没配对，或中文标点混进了代码。

解决：看报错行号，检查括号引号是否成对；把中文括号「（）」换成英文 ()。

FileNotFoundError: [Errno 2] No such file or directory

路径写错了，或你不在以为的那个目录里。

解决：pwd（Windows 用 cd）确认当前目录，ls（Windows 用 dir）确认文件真的在那。

PermissionError: [Errno 13] Permission denied

没有权限：文件被别的程序占用，或目录不允许写入。

解决：关掉占用文件的程序；不要在系统目录里做实验；Mac/Linux 可试 ls -l 看权限。

ModuleNotFoundError: No module named 'xxx'

引用了没安装的第三方库。

解决：pip install xxx 安装；如果 pip 也报错，先确认 pip 是不是跟 python 一家的：python3 -m pip --version。

终端中文显示乱码（Windows）

CMD/PowerShell 默认编码不是 UTF-8，中文输出变成问号。

解决：先执行 chcp 65001 切换到 UTF-8，再运行程序。

还没解决？把「完整报错信息 + 你执行的命令 + 你在哪个目录」三样记下来，这是提问时最有用的信息。
